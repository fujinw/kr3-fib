# LUMO — магазин дизайнерского света

Контрольная работа №3 по дисциплине «Фронтенд и бэкенд разработка». Тема работы — «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

За основу взят сайт LUMO из КР №1. В проекте пять страниц, свои стили на HTML и CSS и иллюстрации светильников из первой работы. Формы учебные, фильтры показывают устройство интерфейса. Серверной обработки нет.

## Запуск

Откройте `index.html` в браузере. Для проверки через HTTP запустите в папке проекта:

```sh
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Для диалога консультации нужен современный браузер с поддержкой HTML-атрибутов `command` и `commandfor`.

## Адаптивная вёрстка

- На всех страницах есть `viewport`. Файл `responsive.css` подключён после `style.css`. По умолчанию сетки одноколоночные, а медиазапросы с `min-width` добавляют колонки.
- На узком экране ссылки спрятаны под кнопкой «Меню» на `details` и `summary`. При 1024 px открытая навигация возвращается в шапку. Flexbox переносит пункты мобильного меню и кнопки первого экрана на следующую строку, если места мало.
- При 640 px каталог переходит с одной карточки в ряду на две. При 1024 px блок популярных товаров на главной показывает три карточки, а в каталоге место слева занимает панель фильтров. На телефоне фильтры можно свернуть.
- При 768 px текст и иллюстрация на главной, галерея и описание Aster, а также контакты и схема проезда встают рядом. В формах две колонки появляются при 640 px. Поля занимают всю ширину своей колонки.
- Карточки и первый экран используют `srcset` и `sizes` с вариантами WebP. В галерее Aster используется `picture` с WebP и исходным SVG. Размеры изображений ограничены шириной контейнера.
- Таблица Aster остаётся обычной HTML-таблицей с заголовками строк и столбцов. На телефоне ячейки переносят длинный текст. Если таблица станет шире контейнера, прокрутится только её обёртка.

## Доступность

- Ссылка «Перейти к содержанию» видна при первом нажатии Tab и переводит фокус в `main`. Текущая страница отмечена через `aria-current`.
- У полей есть подписи. Фокус на скрытом переключателе доставки выделяет всю карточку. Проверены контраст подписей и видимость фокуса на светлом и тёмном фоне.
- У товарных иллюстраций есть описания, у декоративного знака рядом с текстом LUMO — пустой `alt`. На каждой странице один `h1`.
- Диалог консультации открывается встроенной командой HTML. Фокус переходит в поле имени, Escape закрывает окно, а фокус возвращается на кнопку. При включённом сокращении движения плавная прокрутка отключается.

## Проверка

В Chromium проверены все пять страниц на ширинах 320, 360, 430, 640, 768, 1024 и 1440 px. Горизонтальной прокрутки страницы нет, в том числе при раскрытых меню и фильтрах. Отдельно проверены переход по ссылке пропуска, закрытие диалога через Escape, переключение доставки стрелками, сброс фильтров и валидация заявки.
