# LUMO — магазин дизайнерского света

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

**Тема:** «HTML и CSS: разработка многостраничного сайта».

LUMO — учебный многостраничный сайт локальной мастерской дизайнерских светильников. Проект выполнен только на HTML и CSS, без фреймворков, библиотек и JavaScript.

## Опубликованный проект

GitHub Pages: `https://USERNAME.github.io/kr1-html-css-shop/`

> Перед сдачей замените `USERNAME` на имя своего аккаунта GitHub и проверьте ссылку после публикации.

## Страницы

- `index.html` — главная: hero-блок, преимущества, популярные модели и FAQ;
- `catalog.html` — каталог из шести товаров, статические фильтры, сортировка и хлебные крошки;
- `product.html` — подробная карточка Aster, характеристики, советы и отзывы;
- `order.html` — форма заказа с выбором доставки и сводкой;
- `contacts.html` — адреса, режим работы, схематичная карта и форма обратной связи.

## Реализованные требования

- семантические элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация на всех страницах, якорные ссылки и хлебные крошки;
- карточки товаров с БЭМ-классами и модификаторами;
- таблица характеристик с `caption`, `thead`, `tbody`, `th`, `td`;
- формы заказа и обратной связи с подписями, типами полей и обязательной валидацией;
- модальное окно на CSS через псевдокласс `:target`;
- внешний CSS-файл, CSS-переменные, `:hover`, `:focus-visible`, disabled-состояние;
- Flexbox и CSS Grid;
- позиционирование `relative`, `absolute`, `sticky`, `fixed` и `z-index`;
- локальные SVG-иллюстрации без внешних запросов.

## Самостоятельные доработки

- собственная визуальная концепция и дизайн-система;
- адаптивная раскладка для планшетов и телефонов;
- расширенный каталог: бейджи, категории, старая цена и карточки-модификаторы;
- хлебные крошки, блок FAQ, отзывы и советы дизайнера;
- три сценария получения заказа и наглядная сводка;
- доступность: skip-link, `aria-current`, доступные подписи, живые сообщения форм, заметный фокус, поддержка `prefers-reduced-motion`;
- статическая схема проезда без сторонних карт;
- демонстрационные HTML-формы без серверной обработки.

## Как открыть локально

Откройте `index.html` двойным кликом или запустите простой локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте на GitHub публичный репозиторий `kr1-html-css-shop`.
2. Загрузите файлы проекта в ветку `main`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку `main`, каталог `/ (root)` и нажмите **Save**.
6. Вставьте полученную ссылку в раздел «Опубликованный проект» выше.

## Что рассказать на защите

- `Grid` формирует каталог, сложные двухколоночные блоки и раскладку форм; `Flexbox` используется в меню, кнопках и небольших группах.
- БЭМ отделяет блок (`product-card`), его элементы (`product-card__title`) и модификаторы (`product-card--sale`).
- `sticky` удерживает меню и фильтр, `absolute` размещает бейджи, `fixed` — кнопку «Наверх», `z-index` задаёт порядок слоёв.
- Модальное окно открывается без JavaScript: ссылка ведёт на элемент с `id`, а CSS показывает его через `:target`.
- CSS-переменные в `:root` обеспечивают единые цвета, отступы, радиусы и тени.
- Формы являются учебными и не подключены к серверной обработке.
